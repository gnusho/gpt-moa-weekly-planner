# 모아 주간 플래너 (PWA)

개인용 주간 플래너: 목표/할 일/요일별 일정, 일별·주간 몸무게, 색상 카테고리, 첼시 FC·골든스테이트 워리어스·삼성 라이온즈 경기 자동 표시, JSON 백업/복원. 모바일 대응 및 오프라인 앱 셸.

## 설치/배포

### 권장: Vercel (무료 플랜 사용 가능)
1. ZIP 압축을 해제하고 `weekly-planner-pwa` 폴더의 전체 파일을 GitHub 저장소 루트에 업로드합니다.
2. Vercel에서 해당 저장소를 가져오고 Framework Preset을 `Other`, 빌드 명령은 비워 둔 상태로 배포합니다. **프로젝트 루트가 index.html 폴더여야 합니다.**
3. Vercel HTTPS 주소를 휴대폰/PC 브라우저로 열고 브라우저 메뉴 → '앱 설치' / '홈 화면에 추가'를 선택합니다.
4. Vercel이 `api/samsung.js`를 서버리스 함수로 실행합니다. 삼성 라이온즈 경기는 이 API가 정상 작동해야 표시됩니다.

### 로컬 테스트
`python -m http.server 8000` 실행 후 http://localhost:8000 접속. 목표/체크리스트/체중/카테고리는 정상 작동합니다. 삼성 일정은 로컬 정적 서버만으로 가져올 수 없고 배포 후 확인해야 합니다. ESPN은 브라우저 CORS 또는 외부 API 변경에 따라 조회 실패할 수 있습니다.

## 데이터 주의
- 개인 플래너 데이터는 **현재 브라우저 localStorage**에 저장됩니다. 서버 계정 동기화는 구현되어 있지 않습니다.
- 설정 → '데이터 백업'으로 JSON을 다운로드하고 복원할 수 있습니다.
- 이 PWA는 설치가 가능한 **웹앱**이지 앱스토어에 등록된 네이티브 앱이 아닙니다.
- 오프라인 상태에서 이미 캐시된 UI/기록은 사용 가능하지만 경기 일정 신규 조회는 인터넷이 필요합니다.
- ESPN 및 네이버 스포츠의 **비공식/비보장 API**에 기반합니다. 서비스 제공자의 정책 변경, 경기 일정 변경, CORS 제한으로 일정 조회가 실패할 수 있습니다. 실패 시 이전에 가져온 일정은 유지되며, 가짜 경기 데이터는 표시하지 않습니다.
- 첼시 FC는 프리미어리그(`eng.1`) 경기 기준입니다(컵대회/유럽대항전 제외).
- 기록 데이터는 URL 또는 다른 기기에서 자동 공유되지 않습니다.
